# FORGE — физический конструктор

Песочница без заготовок: машины собираются из балок, пластин, кругов (тяни-толкай → колёса),
подшипников, шарниров, амортизаторов, шестерён, электромоторов и ДВС. Физика — Rapier, графика — Three.js
(HDR-небо, PBR, GTAO, bloom). Передаточные числа, массы и реактивные моменты считаются из геометрии и материалов.

Онлайн: https://grzxk.ru/sim/

## Локальный запуск
Windows: двойной клик по `start.bat` (нужен Node.js 18+). Или:

```bash
npm install
npm run dev
```

## Управление
Строительство: B балка, R прямоугольник, P многоугольник, C круг, T тяни-толкай, J соединить, N подшипник,
H шарнир, U амортизатор, G шестерня, M мотор, I ДВС, K сиденье, L провод, V выбор, X удалить, O материал.
Q/E — плоскость вверх/вниз, 1/2/3 — XZ/XY/YZ, Tab — ось, Shift — вертикаль, Ctrl+Z/Y.
Испытание: F5, W/S газ, A/D руль, Пробел тормоз, C камера, R перезапуск, Esc назад. Полная справка — F1.

## Структура
- `src/parts` — типы деталей (геометрия, масса, коллайдеры, поля инспектора)
- `src/build` — редактор: рабочая плоскость, привязки, инструменты
- `src/sim` — сборка блюпринта в физику (`Assembler`), трансмиссия (`Drivetrain`), режим испытания
- `src/render`, `src/ui`, `src/audio` — графика, интерфейс, процедурный звук
